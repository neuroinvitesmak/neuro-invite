# NEURO INVITE — прототип 0.2

## Что добавлено
- Главная страница и каталог шаблонов.
- 6 демонстрационных дизайнов по категориям.
- Переход из карточки шаблона в редактор.
- Поля события и живой предпросмотр.
- Выбор фото и аудио с локальным предпросмотром.
- Сохранение черновика в localStorage текущего браузера.

## Важно
Это frontend-прототип, а не опубликованный сервис. Пока нет регистрации, облачной базы, загрузки файлов на сервер, публичных страниц приглашений, RSVP, QR-кодов и реальной оплаты. Черновик и выбранные файлы не синхронизируются между устройствами.

## Запуск
Требуется Node.js 18.17+:
1. `npm install`
2. `npm run dev`
3. Открыть `http://localhost:3000`
